# Theme-park-sql
This database is a Theme Park / Amusement Park Management System. It handles visitors, tickets, rides (attractions), employees and ride measurements, maintenance, and employee certifications.

DML(Data Manipulation language) files - sql queries that manipulate data

DDL (Data defination langage) files - sql queries that create schema
